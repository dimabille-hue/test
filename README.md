# Архив документов о собственности недвижимости

Python-прототип приложения для оцифровки бумажного архива недвижимости организаций и физических лиц. Приложение показывает, как хранить карточки объектов, историю изменения прав, связанные документы и автоматическую проверку разрывов прослеживаемости.

## Возможности прототипа

- серверный рендеринг HTML на Python без JavaScript и внешних runtime-зависимостей;
- поиск по кадастровому номеру, адресу, типу объекта и текущему правообладателю;
- фильтрация по типу правообладателя: организация или физическое лицо;
- фильтрация по полноте досье;
- карточка объекта с текущими сведениями, историей прав и реестром документов;
- выявление событий права, у которых отсутствует подтверждающий документ;
- отдельный блок с предлагаемым процессом оцифровки бумажного архива;
- дорожная карта развития прототипа до промышленной системы.

## Запуск

```bash
python3 main.py
```

После запуска откройте `http://127.0.0.1:4173`.

## Проверки

```bash
python3 -m unittest
```

Тесты покрывают доменную логику и WSGI-рендеринг: поиск и фильтрацию объектов, сортировку событий по датам, контроль связей между событиями прав и документами, а также отдачу HTML-страницы приложением.

## Структура

- `archive_app/domain.py` — доменная модель архива, тестовые объекты недвижимости и функции прослеживаемости.
- `archive_app/web.py` — WSGI-приложение, серверный HTML-рендеринг и обработка фильтров из query string.
- `static/styles.css` — стили интерфейса.
- `tests/` — unittest-проверки домена и веб-слоя.

## Развитие до промышленной системы

В интерфейс добавлена дорожная карта из шести направлений, которые превращают демонстрационный прототип в эксплуатационный контур:

1. **Авторизация и роли** — архивариус, регистратор, юрист и аудитор получают разные права на просмотр, загрузку, проверку и утверждение документов.
2. **Загрузка сканов в объектное хранилище** — каждый файл получает карточку с размером, типом, контрольной суммой SHA-256, антивирусной проверкой и политикой хранения оригиналов.
3. **OCR-пайплайн и ручная верификация** — система распознает даты, номера договоров, стороны и кадастровые номера, а оператор подтверждает реквизиты с низкой уверенностью.
4. **Неизменяемый журнал действий** — все изменения фиксируются с пользователем, временем, IP-адресом и цепочкой хешей для контроля подмены записей.
5. **Интеграции с ЕГРН, внутренними реестрами и ЭДО** — карточки можно сверять с официальными и корпоративными источниками, а входящие документы прикреплять к событиям прав.
6. **Версионирование карточек объектов и документов** — черновики, утвержденные версии, сравнение изменений и восстановление предыдущего состояния сохраняют прослеживаемость правок.
